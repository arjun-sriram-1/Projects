# Build Feature Prompt

Before coding:

- Identify the closest module `AGENTS.md`.
- Load only the rule files listed for feature work.
- Confirm how the feature supports the trade credit workflow.

While coding:

- Keep route, service, model, and storage responsibilities separate.
- Use existing dependencies and local patterns.
- Persist auditable outputs where required.
- Add focused tests for formulas, APIs, or workflows touched.

Do not:

- Add isolated features that do not support credit decisions.
- Invent financial numbers or final recommendations.
- Add new dependencies without justification.
